# Existing infographics and web artwork

Priority: original uploaded event posters > linked relevant artwork > offline custom fallback.

Three directly linked third-party event images are used where already identified in source data (Mexico City, Sendai, India Festival of Lights). If they fail to load, local poster automatically appears. Third-party material remains credited via source links and is not represented as original AlfaMitsu artwork.

For other November events, relevant Pokémon GO Hub monthly infographic or Leek Duck detailed event guide is linked on the detail screen instead of falsely claiming that a simple promotional banner is an infographic. Other generic posters remain local until corresponding verified graphic URLs are found.

Sources: https://pokemongohub.net/post/event/pokemon-go-november-2026-events/ and https://leekduck.com/events/pokemon-go-wild-area-2026-global/

Deployment: update GitHub with this project or import into Vercel; no remote changes have been published due to GitHub connector 403 write access.
